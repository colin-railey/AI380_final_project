# Requirements — Governance Instability Predictor
 
**Status:** IPR1 baseline (initial criteria, set before any results were seen)
**Notation:** Sₜ ∈ {Stable, Fragile, Unstable}. The test period is 2020–2024 (see Proposal §3.6). "Macro-F1" is the unweighted mean of per-class F1 over the 3 states. Unless stated otherwise, confidence intervals (CIs) are 95% **country-cluster bootstrap** intervals (1,000 resamples of countries), because the country-years within one country are not independent.
 
## Requirements
 
| ID | Type | Requirement | Metric | Acceptance criterion | Rationale | Evidence method |
|---|---|---|---|---|---|---|
| **R1** | Functional | The system shall build a country-year panel (ISO3 × year, 1996–2024) from the WGI 2025-revision and WDI CSVs. Missing values shall be kept as explicit NaN, and the system shall output a per-indicator, per-year missingness report. | (a) Source rows reconciled into the panel; (b) values imputed in the stored panel; (c) indicators covered by the report | (a) 100% of in-scope source country-years appear **exactly once**; (b) **0** imputed values; (c) 100% of indicators | Correct missingness accounting is required for R6–R8. Silent imputation would make the robustness results meaningless. | Unit tests: row counts against the raw CSVs and uniqueness of the (ISO3, year) key. Hypothesis property test: the merge is idempotent and never turns a NaN into a number. |
| **R2** | Functional | The system shall output, for **every** country-year, a nowcast P(Sₜ \| o₁:ₜ) and a one-year-ahead forecast P(Sₜ₊₁ \| o₁:ₜ). This includes years where some or all indicators are missing. | Share of country-years with a valid distribution (all entries ≥ 0, sum = 1 ± 1e-9, no NaN) | **100%**, including country-years with all indicators missing (which reduce to the transition-only prediction) | Output is needed most where data gaps occur. A model that fails or returns NaN in those cases is unusable for the stakeholder. | Hypothesis property tests on random HMM parameters, sequences, and NaN masks. Known-answer test on a hand-computed 2-state, 3-step HMM. Complete-data log-likelihood matches `hmmlearn.score()` within 1e-8. |
| **R3** | Performance | The system shall forecast the next-year stability state on the held-out test period better than a feature-matched baseline. | Macro-F1 of the forecast argmax vs. the true label at t+1; difference vs. multinomial logistic regression (same features, mean imputation) | Macro-F1 **≥ 0.60** **and** **≥ 0.03** above the logistic-regression baseline (point estimate; CI reported) | Chance macro-F1 for 3 classes is ≈ 0.33. A score of 0.60 is a meaningful gain without assuming we beat persistence. A margin of 0.03 is the smallest gain that justifies the added model complexity, and it is larger than the seed variability allowed by R9. Persistence accuracy is **reported** for context but is not a target, because it uses the true PV state at t, which the model never sees. Revisit at IPR2 using validation results only. | Comparative experiment on the 2020–2024 test set. Baselines: majority class, logistic regression, and persistence (reference only). |
| **R4** | Performance | The system shall detect upcoming state transitions. | Among test country-years where the true state changes from t to t+1: **recall** of transition alerts (forecast argmax ≠ nowcast argmax, or P(Unstable) > τ); **precision** of those alerts | Recall **≥ 0.40** at precision **≥ 0.30** | Persistence has 0 recall by construction, so this is where the AI must add value. Transitions are rare (estimated at 5–10% of country-years), so 0.30 precision is roughly a 3–6× improvement over the base rate, which is enough to justify an analyst's attention. With only about 50–100 test transitions, CIs will be wide and will be reported. | Comparative experiment against persistence and logistic regression. τ is tuned on the 2017–2019 validation data only. A precision–recall curve is reported. |
| **R5** | Quality | The system shall produce calibrated probabilities. | (a) Multiclass Brier skill score against a climatology baseline (training class frequencies); (b) expected calibration error (ECE, 10 equal-width bins, max-probability) | (a) Brier skill score **> 0** (CI lower bound > 0); (b) ECE **≤ 0.10** | Analysts act on probabilities, not only labels. An ECE of 0.10 is acceptable for coarse risk tiers. A model with BSS ≤ 0 adds no probabilistic information beyond base rates. | Reliability diagrams and Brier decomposition on the test set, for the nowcast and the forecast. |
| **R6** | Robustness | The system shall degrade gracefully when indicators are missing, including when the missingness is related to instability. | Drop in macro-F1 compared with the unmasked test set, averaged over 20 mask seeds (± SD) | **MCAR 30%:** drop **≤ 0.10**. **MNAR 30%** (masking rate doubled for Fragile/Unstable years): drop **≤ 0.15**. In both cases the drop must be **smaller than the logistic-regression + mean-imputation baseline's drop**. | 30% is a plausible missingness level for WDI social indicators in low-income countries, to be confirmed with the R1 report. A drop of 0.10 keeps the model usable. MNAR is allowed more because it violates the MAR assumption behind exact marginalization, and it reflects the real pattern in the data. The comparison with the baseline isolates the value of marginalizing instead of imputing. | Masking experiment (Proposal §3.4) at m ∈ {0, 10, 30, 50}%, plus block removal of each indicator group. The degradation curve is reported for both Model A and Model B. |
| **R7** | Robustness | The system shall stay stable when indicator values are unreliable within their documented measurement error. | Drop in macro-F1 under noise: WGI + N(0, (c·SE)²) using the **published WGI standard errors**; WDI ± relative noise. 20 noise seeds. | c = 1 (WDI ±10%): drop **≤ 0.05**. c = 2 (WDI ±20%): drop **≤ 0.10**. | Noise at 1 × SE is uncertainty the data producer already acknowledges, so the model should not be fragile within the stated margin of error. A 2 × SE level tests resilience beyond that. | Noise-injection experiment. Results are compared with the same noise applied to the logistic-regression baseline. |
| **R8** | Safety / responsible use | The system shall (a) never output a state label without its probability distribution, and (b) attach a **low-information flag** to any output where more than 50% of indicators are missing for that country-year or the maximum posterior probability is below 0.50. | (a) Share of outputs that include a probability; (b) share of qualifying outputs that are flagged | (a) **100%**; (b) **100%**. Accuracy on flagged outputs is also reported separately. | Without the flag, a posterior that has fallen back to the prior can look like a confident judgment about a data-poor country. That could cause real harm if a user reads it as evidence. The 50% thresholds mark the point where most evidence is missing or no state has a majority. | Unit and property tests on the output schema. Audit script over the full test output file. Stratified accuracy table (flagged vs. unflagged). |
| **R9** | Reliability | The system shall give reproducible results that do not depend on a lucky seed. | (a) Bit-identical outputs on re-run with a fixed seed; (b) SD of test macro-F1 across 10 seeds (EM restarts or bootstrap resamples of training countries) | (a) Identical; (b) SD **≤ 0.03** | EM finds local optima, and the dataset is small. An SD of 0.03 is no larger than the R3 margin, so the conclusions do not depend on the seed. | Repeated-run experiment. A CI job re-runs the pipeline and compares the outputs. |
| **R10** | Functional | The system shall report the sensitivity of predictions to each indicator. | For every indicator: drop-one change in macro-F1 and BN mutual information I(Sₜ; O_d), each with a bootstrap CI | **100%** of indicators reported with CIs. The ranking is included in the final report. | This answers the project's stated question: which missing or unreliable indicators hurt prediction most. | Experiment script. The mutual-information code is checked with a known-answer test on a hand-built 2-node BN. |
